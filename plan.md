# Audio

## Ai Transcription
# purpose - Run openAI whisper locally to convert audio into chunks into text

# steps to do Transcription
1. Load the wisper modal once into memory
2. Transcribes each audio chunck one by one
3. Supports translate mode - conver hindi speech directly to english text
4. Combines all chunk transcripts into single and clean transcript
5. Model size is configurable via .env
